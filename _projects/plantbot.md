# PlantBot

PlantBot is an in-progress personal engineering project focused on monitoring and automating plant care through connected sensors, embedded hardware, and practical software workflows.

## Motivation

Plant care benefits from consistent observation: temperature, humidity, light, soil moisture, and environmental changes can all affect plant health. A compact monitoring system provides a structured way to gather those signals over time and helps turn routine maintenance into a more measurable and reproducible process.

## Current Goals

The near-term goal is to build a simple but useful system for collecting environmental data, storing it in a practical format, and exploring how automation can support plant care. This includes a sensor stack, a small embedded controller, and software for logging and analysis.
